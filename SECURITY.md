# Security policy

## Report a vulnerability

Please report vulnerabilities through GitHub private vulnerability reporting. Open this repository's **Security** tab, choose **Advisories**, then **Report a vulnerability**. Do not post sensitive details in a public issue.

We aim to reply within 3 business days.

## Scope

Reports about this check's code, its release workflow, or distributed files are in scope. Please include the affected version or commit, steps to reproduce, and the impact. Do not include secrets or personal information in a report.
